About

Lunareth is an independent Linux operating system project built around a Linux From Scratch foundation.

The project aims to provide a complete desktop operating system with its own package manager, installation system and software repositories.

Features

- Custom package manager — Luna
- Custom installer — Solaris
- RPM package management
- UEFI boot support
- Independent software repositories
- Desktop environment support in development

Project components

Component| Description
Luna| Package manager
Solaris| System installer
Lunareth Base| Core operating system
Lunareth Repository| Software packages and metadata
